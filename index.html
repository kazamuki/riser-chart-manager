If you're wondering whether this is safe

It's a web page. That's the whole thing.

Someone probably sent you a file called Riser_Chart_Manager.html and it looked odd — an attachment that isn't a document and isn't a photo. That's fair. Here is exactly what it is and what it does not do.

No account, ever

Nothing to sign up for, no email address, no password, no license key.

Nothing is uploaded

Your roster and charts are saved as ordinary files in a folder you pick, on your machine. They are never sent anywhere.

Nothing is installed

It doesn't add programs to your computer or change any settings. Close the tab and it's gone.

It works with the internet off

Because nothing is on the other end. Unplug the wifi and keep going.

No tracking

No analytics, no cookies, no ads. This page loads no outside code either.

You can read it yourself

The program is one plain text file. Anyone who knows how can open it and see every line — there's nowhere for anything to hide.

What it does

Built from what directors kept asking for.

  • Drag singers into place. Curved rows, staggered so heads sit in the window of the row in front, with a marked center line.
  • Print big. The chart fills a landscape page with names sized to be read at arm's length — or print the roster on its own.
  • Mark who's away. One button, then click the singers who aren't coming to that performance. They gray out on screen and on the printout.
  • Keep several charts. Contest, holiday show, a small-group set — each one holds its own riser shape and its own people.
  • Start from a spreadsheet. Download the roster template, fill it in, import it. Export the whole thing back out any time.
  • Any voicing. Barbershop, SATB, SSAA, TTBB, or name your own parts and pick their colors.

What's new

Version 1.8 — install it like an app.

Released July 2026

  • Open the app in Chrome or Edge and an ⤓ Install button now appears in the top bar. Press it and Riser Chart Manager gets its own window and its own icon in your Start menu or Dock — no browser tab to hunt for, and it opens even with the internet off.
  • Installing is also the version that can keep your chart file up to date as you work, so the one click is worth it.
  • The button only appears where it actually helps. Firefox and Safari can give you an icon too — bookmark the page or pin the tab — but they still aren’t allowed to write to a file on your disk, so saving there stays “download a copy”.
  • The in-app Help now describes whichever way you’re running it, and the shortcut list no longer offers Save as… in browsers that don’t have it.

Before that, in 1.7: Firefox and Safari stopped showing a filename as though the file were being kept up to date, and downloaded copies are named with the date first so your Downloads folder stays in order.
